# ¡Cierra tu sesión!

El propósito de este repositorio es concientizar sobre los riesgos de dejar sesiones abiertas en diversas plataformas. La exposición de cuentas puede comprometer información sensible o provocar la pérdida irreversible de datos. 

Agradecemos tu comprensión y colaboración para mantener un entorno seguro.
